# Oficina Pontos

Aplicativo local para registrar tarefas e acompanhar os pontos da equipe.

## Abrir

Abra `oficina.html` em um navegador. Para servir a pasta localmente, execute:

```sh
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000/`.

## Primeiro acesso

Crie o administrador com um nome e um PIN de 4 digitos. Entre pela opcao **Entrar como Administrador**. Depois, cadastre os funcionarios em **Equipe > Novo funcionario** e defina um PIN para cada um.

Os dados ficam salvos neste navegador, neste aparelho. Use a opcao **Backup** nas configuracoes para exportar uma copia.
